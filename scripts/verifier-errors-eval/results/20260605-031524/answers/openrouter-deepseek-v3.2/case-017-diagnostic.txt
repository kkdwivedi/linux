The verifier enforces that IRQ flag restorations must follow a last-in, first-out (LIFO) order relative to the saves. The program saves `flags1` first, then `flags2`, but attempts to restore `flags1` before `flags2`. This violates the required nesting order, causing the verifier error.

The fix is to swap the two restore calls so that the most recently saved flag (`flags2`) is restored first.

```diff
--- a.c
+++ b.c
@@ -5,8 +5,8 @@ int entry(struct __sk_buff *ctx)
 
 	bpf_local_irq_save(&flags1);
 	bpf_local_irq_save(&flags2);
-	bpf_local_irq_restore(&flags1);
 	bpf_local_irq_restore(&flags2);
+	bpf_local_irq_restore(&flags1);
 	return 0;
 }
```

```c
SEC("tp_btf/task_newtask")

	u64 bits;
	int ret;

	cpumask = bpf_cpumask_create();
	if (!cpumask)

	bpf_cpumask_release(cpumask);

	return 0;
}
```

- The pointer is passed to `bpf_cpumask_populate`, satisfying the helper's memory type requirements.
- `bpf_cpumask_release()` ensures proper cleanup of the allocated cpumask object.
- The `bits` variable remains on the stack, providing a valid pointer for the second argument.

This fix addresses the verifier's type-checking error while maintaining the original program's logic.

The verifier fails because the byte store at `fp-7` corrupts the pointer stored at `fp-8`. When the pointer is later loaded, it becomes an unknown scalar instead of a valid pointer, causing an invalid dereference.

The smallest fix is to adjust stack offsets so the pointer and byte stores do not overlap. Change the pointer store to `fp-16` and the byte store to `fp-8`, then load the pointer from `fp-16`.

```diff
--- a/original.c
+++ b/fixed.c
@@ -4,11 +4,11 @@
 SEC("socket")
 __naked void entry(void)
 {
 	asm volatile ("					\
-	*(u64*)(r10 - 8) = r1;				\
+	*(u64*)(r10 - 16) = r1;			\
 	r0 = 0x23;					\
-	*(u8*)(r10 - 7) = r0;				\
-	r0 = *(u64*)(r10 - 8);				\
+	*(u8*)(r10 - 8) = r0;				\
+	r0 = *(u64*)(r10 - 16);			\
 	r0 = *(u64*)(r0 + 8);				\
 	exit;						\
 "	::: __clobber_all);
```

This preserves the pointer type when loaded, allowing safe dereference.

The verifier fails because `slice_len` is a global variable loaded from a map, making it an unbounded scalar from the verifier's perspective. The `bpf_dynptr_slice` call requires a bounded length to ensure safe memory access, but `slice_len` could be any 32-bit value.

The simplest fix replaces the variable with the constant `sizeof(buffer)`, which the verifier can track as a known value, ensuring the length matches the buffer size.

The verifier fails because the first argument to `bpf_cpumask_populate` is an invalid scalar value (`0x123456`) cast to a pointer. The verifier requires this argument to be a pointer to valid memory (e.g., stack, map, or context) of type `struct cpumask` (16 bytes), not an arbitrary integer.

### Fix Explanation:
Replace the invalid scalar pointer with a stack-allocated `struct cpumask`. This provides verifier-known memory of the correct type/size.

## Verifier Failure Explanation

The verifier tracks IRQ state with reference IDs to enforce proper nesting:
- At instruction 3: `bpf_local_irq_save(&flags1)` acquires IRQ state with **ref=1** stored at `fp-8`
- At instruction 7: `bpf_local_irq_save(&flags2)` acquires IRQ state with **ref=2** stored at `fp-16`

The verifier enforces **LIFO (Last-In-First-Out) ordering** for IRQ state restoration. The most recently saved IRQ state (ref=2 at insn 7) must be restored first.

However, the source code restores them in wrong order:
- Instruction 9: `bpf_local_irq_restore(&flags1)` tries to restore ref=1 first
- But verifier expects ref=2 to be restored first (it was the most recently acquired)

The error message is clear: "cannot restore irq state out of order, expected id=2 acquired at insn_idx=7"

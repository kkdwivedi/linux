## Explanation

The BPF verifier enforces that `bpf_local_irq_save`/`bpf_local_irq_restore` pairs are used in strict **LIFO (last-in, first-out)** order, like a stack. The program saves in the order `flags1 → flags2` but then tries to restore in the order `flags1 → flags2` (same order), which violates the requirement. The verifier expects the innermost save (`flags2`, id=2) to be restored first.

## Fix

Swap the two restore calls so they are in reverse (LIFO) order:

```c
#include <vmlinux.h>
#include <bpf/bpf_helpers.h>

SEC("?tc")
int entry(struct __sk_buff *ctx)
{
	unsigned long flags1, flags2;

	bpf_local_irq_save(&flags1);
	bpf_local_irq_save(&flags2);
	bpf_local_irq_restore(&flags2);   // restore inner (flags2) first
	bpf_local_irq_restore(&flags1);   // then restore outer (flags1)
	return 0;
}
```

The only change is swapping lines 248 and 249: restore `flags2` (the last saved) before `flags1` (the first saved), satisfying the verifier's LIFO requirement.

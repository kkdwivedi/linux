### Verifier Failure Explanation

The verifier is rejecting the eBPF program because of a **context safety violation**:

1. The program calls `bpf_local_irq_save()` at line 498, which enters an **IRQ-disabled region** (critical section).
2. Inside this critical section, it calls `helper_a(0)` at line 499.
3. The function `helper_a` is marked as **sleepable** (global function with potential for sleeping behavior).
4. The verifier disallows calling **sleepable functions** while in an **IRQ-disabled context**, since such functions might sleep and cause system deadlock or latency issues.

This leads to the error message:
```
sleepable global function helper_a() called in IRQ-disabled region
```
